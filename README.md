# Мой первый проект (Frontend)

Этот проект создан для восстановления навыков веб-разработки и подготовки к собеседованию.

## 🚀 Что реализовано:
- Адаптивная вёрстка (Mobile-first, CSS Grid, Flexbox)
- Препроцессор SCSS (переменные, вложенность)
- Интерактивный слайдер на чистом JavaScript
- Загрузка данных с внешнего API (fetch, async/await)
- Базовая настройка Webpack для сборки проекта
- Оптимизация изображений (lazy loading) и метатеги

## 🛠️ Технологии:
HTML5, SCSS, JavaScript (ES6+), Git, Webpack
